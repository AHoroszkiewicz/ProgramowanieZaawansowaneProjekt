
## Instrukcja pierwszego uruchomienia projektu

- Wymagania wstępne:
    - .NET SDK wersja 8.0.11

    - Visual Studio (wskazana wersja 2022 lub nowsza)

    - Uruchom plik: PartyTavern/PartyTavern.sln

- W konsoli menedżera pakietów wpisz polecenie “update-database”.
- Uruchom projekt przyciskiem Start lub F5.
- Pierwsze logowanie:
    - Konto admina: admin@admin.admin:Admin123!
    - Konta użytkownika można utworzyć klikając przycisk “Rejestracja” (nie zapomnij potwierdzić emaila na stronie po rejestracji).
- Baza gier domyślnie jest pusta, więc należy zalogować się na konto administratora i dodać grę (bądź kilka) klikając przycisk Gry>Dodaj nową grę.
- Zarządzanie drużynami:
    - By założyć drużynę należy kliknąć Drużyny>Stwórz nową drużynę.
    - By zobaczyć szczegóły drużyny należy kliknąć przycisk szczegóły znajdujący się obok niej.
Opcje edytowania/usuwania/dołączania do drużyny oraz komentowania są dostępne tylko dla administratora bądź twórcy drużyny/komentarza z widoku szczegółów.
- Propozycje gier:
    - Użytkownik może złożyć propozycje dodania nowej gry przez przycisk “Dodaj propozycję gry!!”.
    - Administrator może zobaczyć propozycje w widoku “Propozycje gier”.
